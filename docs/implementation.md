# 二、软件实现与协议

## 从摄像头到报警

| 程序 | 职责 |
| --- | --- |
| [nano_contest.py](../source/nano_contest.py) | 桌面入口，协调相机、环境和 PLC 工作线程，显示报警原因、设备回读和复位结果 |
| [nano_bottle_check.py](../source/nano_bottle_check.py) | 用 GStreamer 采集 USB 画面，分析演示瓶瓶盖和标签的位置关系，输出直立、倾倒或未知 |
| [nano_zone_check.py](../source/nano_zone_check.py) | 红胶带区域检测与早期独立调试入口 |
| [nano_virtual_zone.py](../source/nano_virtual_zone.py) | 自定义多边形、空场标定、区内前景检测和区外光照参考 |
| [nano_environment.py](../source/nano_environment.py) | 轮询探头、换算三路物理量、写入 PLC 并读回核对 |
| [nano_trends.py](../source/nano_trends.py) | 从采样历史绘制最近五分钟曲线，掉线处留空 |
| [nano_plc_check.py](../source/nano_plc_check.py) | Modbus TCP 报文、视觉心跳、状态字解析与独立通信检查 |

**警戒区模式。** 设置时依次点选 3 至 12 个顶点，检查重复点、交叉边和最小面积。镜头固定、区域清空后采集参考画面。已存在的胶带加入掩模，区外样本用于估计曝光变化。确认入区与确认清场分别上报，因此遮挡、未知帧或通信中断不会直接解除已有报警。

**样品瓶模式。** 初版会把背景里的相似色块判断成瓶子。最终流程先在画面中确认直立，由操作者点击开始检测；倾倒需要持续确认。丢失目标后取消布防，换场地重新确认目标。该方法针对演示瓶的可见标签和瓶盖，透明无标签瓶与严重遮挡尚待测试。

## Nano 和 PLC 如何交换状态

| PLC 地址 | 内容 | 写入者 |
| --- | --- | --- |
| %MW1000 | 视觉事件、在线标志、清场或直立标志，高字节为滚动心跳 | Nano |
| %MW1001 | 光、热、人员、瓶倒、视觉在线、红灯、蜂鸣器以及软件复位支持位 | PLC |
| %MW1002–1004 | 温度、湿度、照度原始值 | Nano 写后读回 |
| %MW1005 / %MW1006 | 软件复位请求编号 / 已执行编号 | Nano / PLC |

PLC 的循环任务周期设为 20 ms，监测心跳变化的超时设为 3 s。点击复位后，Nano 结束本轮视觉检测并写入新的请求编号。PLC 处理锁存状态，抑制旧视觉事件，写回确认编号。Nano 等待对应回执，再显示红灯和蜂鸣器的输出状态。若外部光、热输入持续触发，PLC 可消音并保留灯光提示。

## 温湿光数据怎样验证

程序向网关读取从站 1 的七个保持寄存器，取下标 1、0、6 分别作为温度、湿度、照度。温湿度按十分位换算，照度倍率依据探头型号配置。轮询间隔约两秒，超过六秒的旧样本不再同步。PLC 若报告不支持批量写，程序退回逐字写入，再读回连续三个字并检查是否一致。这样现场人员能分辨“探头有更新”和“PLC 已确认”。
