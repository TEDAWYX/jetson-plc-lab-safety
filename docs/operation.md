# 实验台安全演示

## 队友现场操作

1. 给 Nano、PLC 和交换机上电。把 Nano 显示器接好，双击桌面上的 **实验台安全演示**（英文桌面显示 **Lab Safety Demo**）。若第一次出现“允许启动”或“信任并启动”，确认这是刚安装的图标后点击确认。
2. 先对准地面，确保警戒区没有人，再点 **人员警戒区**。机位有变动时点 **重新划区**，沿边界依次点四角，再点 **保存警戒区**。画面显示“警戒区正常”后，单脚踏入，再完全退出。观察红灯和蜂鸣器是否随之恢复。
3. 转动相机对准直立的样品瓶，再点 **样品瓶倾倒**。出现“样品瓶直立”后点 **开始瓶倒测试**，再放倒瓶子。确认红色 **WARNING · 样品瓶倾倒**、红灯和蜂鸣器。
4. 点击画面下方 **一键复位**。PLC 确认后，当前视觉报警解除并结束该轮检测。重新选择项目即可开始下一轮。光、热输入仍在报警时蜂鸣器会停，红灯会继续提示。演示结束点 **退出**。

窗口显示的是 PLC 回读的输出状态。若窗口显示“蜂鸣器停”，现场却仍有响声，检查洞洞板的供电与继电器输出。

## 赛前只做一次

- **Nano 安装。** 将 `Install-Nano-Contest.cmd` 和 `Nano-Contest.zip` 放在 Windows 同一目录。连原来的热点，双击 CMD 文件，按提示在本机输入 Nano 登录密码和 sudo 密码。安装写入 Nano 桌面图标和有线 `eth0` 的固定地址 `192.168.3.10/24`，有线接口用来访问 PLC `192.168.3.130`。热点地址有变化时，把 CMD 第 3 行改为当前地址。竞赛当天从 Nano 本地启动。
- **环境探头。** 在 Nano 窗口点击 **传感器设置**，填塔石转换器的实际 IP，点 **保存并连接**。配置只需填一次。看到温度、湿度、照度后遮一下感光头，确认照度有变化。界面会标明 PLC 是否已回读确认。照度倍率按传感器的型号和说明书选择。
- **实时曲线。** 点击主窗口读数右侧的 **实时曲线**，查看最近五分钟的温度、湿度和照度。采样从桌面程序启动时开始，断线时曲线留空。
- **PLC 程序。** 软件复位版已在比赛用的 TM12002 上运行。重新下载时，使用 CODESYS 打开 `LabSafety-TM12002-SoftReset.project`。这台 PLC 拒绝了 CODESYS 的“创建启动应用”命令，断电重启后请检查屏幕上的“一键复位”能否收到 PLC 确认。
