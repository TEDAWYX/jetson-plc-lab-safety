# 一、硬件组装与接线

## 按信号方向组装

| 部件 | 接到哪里 | 联调时看什么 |
| --- | --- | --- |
| UC60 USB 摄像头 | Jetson Nano 的 USB 口 | 用 V4L2 核对设备名，抓取一帧确认镜头方向、亮度和目标位置 |
| 温湿光三合一探头 | RS-485 数据对接 TAS-LAN-460 的 A+、B−，电源接符合探头铭牌的直流供电 | 核对本机线序和极性，遮住感光头后观察照度能否变化 |
| TAS-LAN-460 | 以太网口接交换机，端子 VIN、G 为网关供电 | 确认串口参数与探头一致，Nano 能轮询到三个量 |
| Nano 与 TM12002 | Nano 有线口和 PLC 的 TCP 口接入交换机 | 通过有线接口访问 PLC，同时可通过热点 SSH 调试 Nano |
| 声光报警板 | PLC 继电器输出控制低压负载回路，工程映射 Q4 为红灯、Q5 为蜂鸣器 | 分别核对 PLC 输出位、继电器动作和负载实际状态 |

## 洞洞板如何分区

上部留给直流降压模块，中部放指示灯、限流元件和蜂鸣器，下部引出控制线。装配时先断电，用通断档从每根甩线追到对应焊点，标出公共线、灯支路和蜂鸣器支路。三根同色导线无法从外观确定用途。电源端按实物标识区分直流输出和交流输入，负载端依据元件额定值核对降压输出。无源蜂鸣器持续发声还需要振荡驱动，继电器承担通断控制。

## 怎样判定接通

先看摄像头图像，再看环境数值能否随遮光变化，然后读取 PLC 状态字。最后分别触发人员、瓶倒事件，对照画面原因、PLC 输出位和实物声光。曾出现软件显示输出有效、现场蜂鸣器线已断开的情况，因此记录测试结果时要注明观察的是哪一端。
