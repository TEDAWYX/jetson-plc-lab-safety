# 六分钟答辩怎样从论文讲到实物

[下载九页决赛 PPT](final.pptx) · [下载评委问答与论文衔接稿](defense-qa.docx)

下面的时间用于复讲排练。两名队员可以分别负责讲解和操作，操作员在第七页完成现场演示。

| 页 | 建议用时 | 讲什么，给评委看什么 |
| --- | --- | --- |
| 1–2 | 45 秒 | 从一次进入警戒区的动作讲起，引出操作台的三个观察对象。人和瓶子会产生离散事件，温湿光则要连续观察。 |
| 3–4 | 75 秒 | 把论文里的感知、决策、执行对应到摄像头与环境探头、Nano、PLC。沿图走一遍返回路径，解释显示屏如何知道 PLC 已经响应。 |
| 5 | 50 秒 | 说明为什么需要空场和直立样本。单脚进入后要等清场，瓶子倾倒后要能复位；机位或演示瓶变化会影响识别。 |
| 6 | 40 秒 | 用实测图指出温度、相对湿度和照度的单位。请评委关注遮光前后的照度变化，以及界面何时收到 PLC 的确认。 |
| 7 | 90 秒 | 队友依次演示单脚进入再退出、切换模式后让瓶子倾倒、点击复位。讲解者同时指出报警原因、现场灯和 PLC 状态。 |
| 8–9 | 60 秒 | 把单工位结果与校级监控的设想分开讲。增加工位后需要解决设备标识、状态汇总、告警追溯，以及跨场景的误报评估。 |

若被问到“一只脚也能识别吗”，说明这版程序检测的是区域内相对空场的前景变化；脚可以触发，其他足够大的物体也可能触发。若被问到“论文里的多智能体在哪里”，可用第 3 页解释本次实现的感知、状态仲裁和执行分工，再用第 8 页说清后续扩展。两处回答都可以回到[实现说明](../docs/implementation.md)核对。
